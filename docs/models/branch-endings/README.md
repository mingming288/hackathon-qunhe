## 交付与接入边界

- 交付九个独立的真实模型文件、生成任务记录摘要与统一离线预览，不将方案文件冒充模型。
- 房间采用屋顶和前墙敞开的展示方式，给第三人称镜头保留视野。模型必须检查侧面厚度、后墙、入口与地面的完整性。
- 生成式建模不能保证门洞与尺寸精确遵从坐标。正式替换游戏环境前，需要校准尺寸、门洞、碰撞和交互点，不直接覆盖当前可运行场景。
- 本批报价不含完整场景装配、动画、骨骼和人物。当前未检测到可用的本地场景装配工具；源模型生成可以先进行，精确校准与完整装配阶段另行解决该依赖。
- 风格通过后继续独立制作家具道具，同款共享资产复用实例，不为每个摆放点重复生成。
