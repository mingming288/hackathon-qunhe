# 禁闭室 · 单张多视图设定与单模型试样

当前只生成了一张建模设定图；尚未获得图片确认，未提交新一轮三维生成，也未接入游戏。

## 设定图内容

同一张图片中包含整体透视、正面、背面、左右侧面、俯视尺寸、拆件建造，以及铁门、墙面、草席与石板的细节。

风格以旧式监狱的厚石墙、旧水泥、灰绿剥落漆层、锈铁门窗和压抑光线为基础，提高结构与材质细节，减少玩具积木感。
尺寸属于设计参考，多视角构造与隐藏部分仍须在实际建模时核对，不将生成图片等同于精确施工图。

## 用户明确要求的顺序

1. 用户先检查并确认这张设定图。
2. 根据确认后的图片，准备禁闭室一个三维试样的具体制作方案与真实报价。
3. 取得所需费用确认后，只执行这一处试样；墙体、门扇、门框、地板与独立道具保持可分别控制。
4. 用户看到并认可三维试样效果后，才扩展其他三维模型。
5. 只有明确确认过的模型，才可按后续指令接入游戏。

这张设定板不能作为一张包含多个房间的整体输入直接生成三维。进入建模阶段后，须将确认设计整理为一致的资产专用参考，分别处理结构和道具。
