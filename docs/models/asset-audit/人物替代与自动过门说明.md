# 人物替代与自动过门

海伍德暂用已有人物三维模型，弗洛伊德暂用汤米模型；超市经理和银行职员暂用典狱长模型。角色姓名、对话和剧情身份保持独立，替代外观并非最终定稿。牢房检查时的狱警也接入已有狱警模型；目前该模型没有专门的行走动画。

主角及已配置的人物在模型加载期间不再显示基础方块人物；场景加载时会等待人物资源或显示加载提示，超时后继续加载，资源失败时提示并恢复基础形象。修复切换场景时行走动画尚未加载完成导致待机混合器丢失的问题。正式场景需要较多模型资源，最长等待八秒后会继续显示；不等于所有设备均已达到流畅性能。

开放入口现在由玩家移动接近后自动切换，主线任务中的管网出口也沿用此规则；未开放入口仍受剧情条件限制，可交互物品和对话仍用空格或点击。为防止切换后立即返回，出生时已经站在入口触发范围内的情况须先离开入口再重新靠近。检查期间不自动离开牢房。

浏览器实测开场主角、院子中海伍德替代形象、牢房到走廊、院子到图书馆和图书馆返回院子，未开放的挖掘入口未误切换；自动检查覆盖全部人物模型配置、入口可达、锁定与暂停、返回入口防抖和人物动画加载竞态。自动测试及构建通过。完整剧情、各结局和不同电脑上的性能仍需继续人工验收。
