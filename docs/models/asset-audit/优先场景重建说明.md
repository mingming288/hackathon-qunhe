# 优先场景重建说明

本批按监区走廊的制作方式，重建牢房、院子和图书馆建筑主体，并接入三维游戏。墙面、地面采用相同的独立石材贴图；牢房高窗增加铁栅，院子增加围墙、两座瞭望塔及道路。现有家具、人物、院子两栋建筑外观与剧情目标继续复用。

建筑尺寸沿用原场景的游戏坐标，碰撞、场景入口和剧情事件不随模型文件替换而变化。牢房海报后的通道仍使用原有转场，并非本次制作了可行走的真实洞口。院子建筑外观和图书馆书架仍为既有模型，尚需统一细节和风格。

重建脚本为 `apps/game-3d/scripts/build-priority-scenes.py`。
中文说明：优先场景建模脚本，调用同目录的走廊材质和几何函数生成可复现的场景主体。

使用的材质来源及许可见 `apps/game-3d/assets/corridor-textures/来源说明.md`。
中文说明：走廊与本批场景共用的材质来源和许可记录。

已有测试覆盖场景入口可达及剧情状态；环境预览已查看三个场景。需要在目标电脑进一步测试帧率、视觉细节和完整剧情通关。其余场景尚未按此方式重建。
