# 禁闭室贴图优化

禁闭室建筑、草席和石板的内嵌基础颜色贴图保留原始分辨率，使用高质量有损压缩；透明材质及金属度、粗糙度等非颜色贴图不转换。三份模型合计由 47,527,940 字节减少至 32,035,456 字节，约减少百分之三十二点六。这是文件传输体积的比较，不代表显存或帧率同幅改善。

对优化前后的模型进行检查：节点、网格、顶点访问器、材质参数和贴图引用一致，未转换的二进制资源逐字节一致；模型三角面数与边界不变。浏览器中放大检查草席、石板与墙面，未发现明显画质变化或加载报错；自动测试及构建通过。尚未进行不同设备、网络条件下的加载耗时和帧率对比。

优化脚本使用系统图片转换工具，仅处理单个内嵌缓冲区内、由不透明材质使用且不与其他贴图用途共享的颜色图。重新提取道具或重新导出建筑后，需要对输出文件再次执行优化；原版本可以从版本记录或独立模型项目获取。
