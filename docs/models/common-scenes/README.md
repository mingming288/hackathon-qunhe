## 审核重点

- 与已生成禁闭室的风格统一
- 牢房床左桌右与后墙海报位置

- 各视角的门窗、方向和资产结构一致性

## 建模前需核对

- 设定板用于集中审阅，不等同于精确施工图或可直接导入的三维模型。
- 标注的13×13、13×29与40×38是当前游戏布局单位，不是米制建筑尺寸。
- 正式建模前需从确认稿整理单件资产参考图，并校核正交视图方向、门窗数量、尺寸、厚度和可操作部件。
- 牢房拆件示意未单独展开床，床需要作为独立资产制作。

图片审核通过后，再整理对应的独立资产图与细节说明，用于后续建模。三维模型与游戏接入分别验收。
