## 查看与审核

打开 [图片审核总览](index.html)。默认展示前期准备，可按游戏流程、场景或物品筛选，并点击缩略图查看高清原图。勾选“显示已有参考”可查看复用来源。

实际生成进度、失败项、图片来源、分辨率和文件校验见 [审阅清单](review-v1.json)。生成期间总览按已归档结果更新，不把排队任务计作完成。

本批已完成七十七项新增图片，待生成和失败均为零，全部等待用户审核。十五处新增场景与六十二张物品或模块图共同构成当前审阅版本；另外复用八份已有参考。

## 审核与建模边界

1. 先检查画风、外形、场景布置与通路，再检查同一资产不同视角是否一致。
2. 门、盖、抽屉、旋钮、齿轮、书封、书页、车轮等活动部件保持可分；道具不与房间或地形融合。
3. 纸面文字、身份资料、地图路线、证据关联、牌匾和商品标签以游戏实际绘制为准；设定图不提供已验证的玩法路线或可读证据正文。
4. 图片仅为审阅设定，尺寸、厚度、门洞、转轴、碰撞、数量与隐藏结构仍须建模前校准。布局单位不是米制施工尺寸。
5. 审核通过后，整理资产专用整体图、独立视角和部件参考；不把含多个视角、状态或物体的整张设定板直接当作单一模型输入。
6. 图片通过、模型通过、游戏接入分别记录；生成图片不代表自动通过验收。

完整提示词、实际参考图片路径和五次修正请求保存在 [提示词记录](prompts-v1.json)，原始范围见 [制作清单](plan-v1.json)。修正过程见 [修订记录](revisions-v1.json)：雨夜出口已畅通，办公室挂画遮挡嵌墙保险柜，橡树线索改为自然深色扁石；空置医疗房间重试后已返回可用图片。旧版保留并在审阅清单中记录，不覆盖原图。

归档脚本 [update-review.mjs](update-review.mjs) 验证真实图片、文件校验、旧版保留与场景物品覆盖，并重建离线总览。审阅图片已保存进仓库，图像工具默认输出目录中的原文件也保留。普通浏览直接打开总览即可，不需要安装依赖或运行脚本。
