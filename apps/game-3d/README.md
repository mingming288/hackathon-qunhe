# 高墙之外 · 第三人称三维剧情贯通版

采用同一仓库内的独立三维应用，原二维游戏及其存档保持独立。
先用基础模型贯通故事，再逐件替换正式模型。剧情、任务前置、备用路线和结局已贯通；关卡小游戏以仓库内原版《高墙之外》为准，精细三维美术与人物动作继续制作。

## 当前可用内容

已接入首批现有模型：牢房铁床、书桌和木椅，图书馆书架和整理桌，以及石锤和碎石。人物及其他陈设仍使用基础模型；生成资产的比例、风格和碰撞仍需继续打磨。场景总览可直接查看牢房、图书馆与挖掘通道。

已接入牢房、走廊、院子、图书馆、禁闭室、手术室和结局场景的现有建筑模型，以及院子里的图书馆和办公楼外观。模型按当前游戏尺寸调整地面、比例与方向，并以简化矩形碰撞维持通路；部分生成模型仍有融合陈设和不规则地形，碰撞与地面高度并非逐三角面精确匹配。海滩移除了海面方向的混合几何并补上海面。牢房海报后仍是交互转场，尚未打通实际洞口；墙后通道生成稿开口和镜头遮挡尚待处理，暂用基础版。没有现成建筑模型的场景继续使用基础版。

- 十九组可进入的三维基础场景，包括序章、监狱、逃离路线及三个结局的空间。
- 可见的第三人称主角，跟随镜头、拖动环顾、缩放和镜头避墙。
- “开始新游戏／继续游戏”按任务和道具条件解锁通路，显示当前目标、方向、随身物品及线索数量。
- 任务栏明确给出目的、逐段路线、目标位置和操作方式；金色标记直接写出下一处入口或要做的事。
- 原版故障检查／四轴齿轮／双旋钮调谐、十本图书排序、拖放藏锤、五秒挖掘、三轮倒土、十秒迷宫与五次雷声砸管。
- 标准准备路线、石锤被没收后的备用路线、五份直接线索和两份旁听记录，连接三个结局。
- “场景总览”随时查看任意地点及资产清单，返回游戏后恢复原任务与位置。
- 剧情与场景查看分别保存；重新开始会备份上一份三维游戏记录，不读写原二维游戏存档。
- 通过本地模型清单替换基础资产，加载失败保留基础模型。

基础人物的走路摆动由程序驱动，只用于空间测试，不冒充已完成的正式角色骨骼或动作。
当前没有新增云端生成任务或消耗生成积分。

首轮资产优化已修复导入模型未投射、接收阴影的问题，人物和家具现在能在正式建筑地面上形成投影。已增加[可重复运行的资产检查与验证记录](../../docs/models/asset-audit/README.md)，记录模型体积、实例面数、材质和场景配置。此项修复不代表建筑贴图、人物风格或目标设备性能已经完成最终验收。

## 这一轮怎样贯通故事

剧情参考仓库中的原游戏主脚本和结局脚本，以独立任务事件组织，避免把旧版全局状态直接复制到三维场景里。

1. 在牢房观察松动的墙面，找瑞德谈妥修理收音机换取石锤的约定。
2. 依原版依次检查故障、修复齿轮传动、主频与微调锁定信号；成功后找瑞德领取石锤。到图书馆在四次交换内把十本书按高度排好，向老布领取圣经。回牢房将石锤拖到圣经上，再站回床边接受检查。
3. 取得海报、持续挖掘五秒拿到碎土；在院子观察巡逻并分三轮倒土，每轮五秒。每轮三秒后最近的狱警靠近，被碰到需从刚取得碎土的进度重新倒土。完成后自动衔接到二十年后。
4. 在牢房完成十秒管道迷宫取得蓝图，再去办公室藏身、找到保险柜并调包账本。最后一夜通道已经贯通，走到出口停留零点三秒进入砸管区域，不另加第二次挖掘。
5. 只在随机雷声窗口内开始按住零点七秒，每次雷声至多成功一次；三次改变管道阶段，五次敲开。静默时敲击会失败，需从砸管前检查点重试。穿过三维管网、进入雨夜与对应结局。

没有藏好石锤就接受检查，会进入禁闭、听取老布建议、办公室搜查和找回工具的备用路线；训诫、等待开门与过夜自动衔接，之后重新汇入逃离主线。风险选择会明确说明没收后果，不与普通主线混为同一种按钮。

自动衔接保留原任务事件，旧存档可逐项重放，再推进到下一项需要操作的任务。自动转场后丢弃旧场景的位置；仍在原场景时保留站位。“场景查看”继续使用独立记录。

| 结局 | 进入条件 | 可游玩顺序 |
|---|---|---|
| 相逢的海滩 | 已取得瑞德线索，且未满足调查结局条件 | 瑞德到橡树根旁开盒读信、乘车赴约、海边重逢 |
| 高墙下的名单 | 五份直接线索，或至少四份直接线索与两份旁听记录 | 核对证据、寄信、调查医疗机构、补全记录、抓捕、结语 |
| 形同陌路 | 不满足以上条件 | 安迪银行取款、沿海驾车、修船；切换瑞德完成超市工作与自主决定 |

调查结局优先判定。普通的“与瑞德交谈”任务不自动取得其线索，需要主动选择追问。角色在对应结局阶段切换，始终使用第三人称镜头。

原版小游戏由三维场景中的任务目标打开，成功事件驱动已有剧情。收音机、图书、地图、寻树、巴士驾驶、超市沿用原版组件或原版具名类与函数；藏锤、持续挖掘、倒土与雷声砸管的判定也在构建时直接读取原版源码。上一版新增的单齿轮、固定频率、三本分类归位、藏锤旋转合书、左右右顺序和三次点击砸管已移除。

小游戏目前保留原版二维操作界面，外围探索采用第三人称三维场景。倒土使用原判定、巡逻区域和速度，在独立操作面板展示；三维院子中的巡逻与动画尚待进一步整合。管道迷宫蓝图由原组件保存，实际三维管网仍由现有场景构成，尚未按蓝图自动重建。办公室潜行、人物表演和三维管道爬行也未在本次完成。

本轮检查聚焦任务能否继续、各分支能否结束、保存能否恢复、查看场景是否影响剧情。碰撞尺寸、镜头遮挡、动作和正式模型尺度留到资产接入后统一打磨。

## 逐步替换正式模型

把文件放进应用的公开资产目录，再编辑模型清单。

- 文件目录：
  `public/assets/models/`
- 模型清单：
  `public/assets/models.json`

清单示例（示例文件不随基础版提供，获得真实模型后再填写）：

```json
{
  "version": 1,
  "models": {
    "red": { "url": "/assets/models/red.glb", "height": 2.5 },
    "bed": { "url": "/assets/models/bed.glb", "height": 1.2 }
  }
}
```

中文字段说明：版本、模型映射、文件地址与目标高度。
使用 GLB（二进制三维模型）格式，文件地址限定当前应用的模型目录，不能填入密钥或临时签名地址。
普通道具按目标高度缩放，脚底归零；可选朝向字段使用弧度。
可用“场景标识:资产标识”只替换某个场景中的同类物件；未指定场景时沿用共享资产。
带骨骼的模型使用保留骨架的复制方式；若文件含动画，基础预览播放实际存在的第一个片段。
待机、行走、持物等动作与任务的切换，属于后续角色控制接入工作。

每个场景还提供“场景标识加建筑后缀”的整体建筑替换位，例如：

```json
{
  "cell-architecture": {
    "url": "/assets/models/cell-shell.glb",
    "normalize": false
  }
}
```

中文字段说明：牢房建筑槽位、模型地址、关闭尺寸归一化。
整体建筑必须使用与基础版相同的米制尺寸、中心原点、地面高度和门洞位置。
建筑替换只更新外观，不自动移动碰撞、人物站位或出入口；这些应在场景验收中同步核对。

当前可复用资产标识包括：床、桌椅、书架、收音机、海报、保险柜、人物、车辆与树木。
具体英文标识集中在场景数据和几何套件中，它们是代码连接键，不是界面文字。

## 玩法完整度核查与建模分级

截至二〇二六年十月三十一日，主线小游戏已切换为原版规则。测试覆盖两条准备路线、三十二种直接线索与四种旁听组合，共二百五十六种剧情情形，并逐步恢复存档；状态测试不能替代三维镜头、模型尺度与动作验收。

### 原版小游戏与接入边界

| 关卡 | 原版操作与判定 | 接入方式 |
|---|---|---|
| 修收音机 | 检查旋钮、指针与齿轮，安装四个齿轮使传动连续，再用主频和微调锁定信号 | 直接加载原组件、种子与样式 |
| 整理图书 | 十本从高到低，每次选两本交换，至多四次；失败重新开始 | 直接加载原组件 |
| 藏锤 | 拖动石锤，中心落入圣经区域后松手；失败回原位。支持空格拿起、字母键移动、空格放下 | 直接读取原判定、布局与绘制函数 |
| 首次挖掘 | 持续互动五秒，松手清零 | 直接读取原判定函数 |
| 倒土 | 三轮各五秒，三秒警觉；狱警触碰失败、清除三轮进度后重试 | 直接读取原判定、目标选择、速度与接近距离，操作面板适配输入 |
| 管道地图 | 十秒内持续拖动找出口；超时原图重试，成功保存蓝图 | 直接加载原组件，仅纠正原来残留的二十五秒说明 |
| 雷声砸管 | 二点一至四点二秒随机间隔，雷声窗口一点五秒，按住零点七秒，一窗一次，五次通关；静默时按下失败 | 直接读取原计时和成功／失败判定，使用原雷声音效 |
| 第一结局 | 操控瑞德寻找真橡树、调查铁盒；操控巴士抵达终点 | 直接加载原结局组件，仅转换资源地址 |
| 第三结局超市 | 四件商品实地收集，四格纸袋拖放／交换，错误装袋可改；随后服务三位顾客，食品与清洁用品分开，第二单后向经理请示 | 直接读取原商店碰撞、收集、排序、三单工作、对话与绘制代码 |

收音机、图书与迷宫在首次打开时延迟加载，不新增前端框架依赖。原项目的运行时、样式、组件、结局类与音效都来自同一仓库；部署时统一打包所需资源，不依赖另一台本地服务或外部网址。原版第三方运行时与字体许可证保留在本应用许可证目录。

任务只接受对应组件发出的成功回调。返回探索、超时、排序失败与加载失败不推进剧情；关闭容器会释放绘制循环、计时器、监听和音频。返回后重新进入当前小游戏；已完成剧情继续沿用原事件标识。旧存档的半完成替代操作不会冒充原版通关，已完成事件和道具不清空。超市作为连续关卡完成后写入对应四个事件，中途退出需从该段入口重来。

场景搭建者继续维护现有建筑、陈设、出入口与碰撞。小游戏只引用稳定任务和资产标识；本次不调整这些场景文件，也不覆盖同事的模型交付。纯环境查看不创建玩法附件或小游戏。

| 倒土与岁月流逝 | 已接入原判定的三轮倒土、巡逻靠近、失败重试 | 把面板中的巡逻移入三维院子，补短演出表现长期准备 | 优先 |
| 办公室 | 交谈、藏身、掀刺绣、调包均可完成 | 典狱长离开后外观仍在；缺少巡查计时、藏身判定、保险柜揭示与账本拿取反馈 | 优先 |

| 橡树、乘车与重逢 | 已接入原版寻树与驾驶，完成后回到三维场景 | 补三维寻树、车辆操作与海滩等候演出 | 随后 |
| 银行、公路与超市 | 原版完整超市收集、排序与三单工作；银行和安迪驾车为叙事转场 | 补三维取物、装袋与人物工作动画 | 随后 |

当前人物基本按场景固定摆放，尚未随剧情切换在场状态。二十年后的老布、典狱长离开办公室、海滩重逢时的安迪与瑞德，需要统一的剧情显隐规则。否则完成建模后，仍会出现人物与对白不一致。

备用路线直接衔接到最后一夜，跳过领取和挂上海报，而后续引导仍称“海报后的通道”。需明确该路线如何准备入口：补一个合并后的准备说明或任务，或者统一修改入口状态与引导，不能仅开放通路。

结局规则为：五份直接线索，或四份直接线索加两份旁听记录，进入调查结局；否则取得瑞德的可选线索进入重逢结局，其余进入各自生活结局。普通主线交谈不算取得瑞德线索。应通过对白和调查反馈让玩家理解这种差异，避免认真完成主线却不明白为何没能重逢。

### 场景使用分类

分类以当前任务路线为依据，并非玩家使用统计。常用程度、剧情重要性与模型数量是不同维度。场景总览可按四类筛选，每处环境的资产清单还列出所需状态，便于场景与玩法同时制作。

| 分类 | 场景 | 使用特点与制作建议 |
|---|---|---|
| 常用往返，三组 | 安迪的牢房、监区走廊、院子与监狱大门 | 准备阶段反复经过，优先统一尺度、入口、碰撞与人物交互位置 |
| 主线关键，六组 | 图书馆、办公室、挖掘通道、砸管处、地下管网、雨夜 | 三个结局前都要经过；砸管和雨夜虽出现少，仍要优先保证玩法与情绪效果 |
| 分支与结局，九组 | 禁闭室、手术室、橡树、公路、海滩、超市、银行、证据整理空间、医疗机构外景 | 按选定分支排期；公路和海滩跨两个结局复用，证据房在调查结局中也会往返 |
| 档案展示，一组 | 电视前的客厅 | 当前新游戏自动跳过，核心体验完成后再精修或恢复开场 |

十九组环境不能直接等同于十九个完整模型。院子里的图书馆与办公楼已有独立外观替换位；房间建筑、家具、互动部件及人物也要分开。主线常用道具如石锤、圣经、海报、收音机、图书、保险柜、账本应比纯背景装饰先完成。

### 三人协作建议

场景搭建者先确认建筑尺度、门口和交互留白，再补陈设与美术；玩法负责人负责前置状态、人物显隐、持物、交互成功与失败反馈。可先用“牢房—走廊—院子—图书馆”验证借锤、得书、藏锤这段完整体验，再制作办公室到雨夜的逃离高潮。分支场景按首版承诺的结局范围推进。

玩法接入尽量保留现有任务事件标识，避免破坏存档。按段验收：能到达、知道为何操作、能看见结果、失败能重试、刷新能继续，最后再检查场景美术与人物动作。功能完整度应按这些实际行为判断，不以“模型已替换”或“任务能通关”代替。
