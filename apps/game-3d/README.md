# 高墙之外 · 第三人称三维剧情贯通版

采用同一仓库内的独立三维应用，原二维游戏及其存档保持独立。
先用基础模型贯通故事，再逐件替换正式模型。当前重点是剧情顺序、任务前置、备用路线与结局可达；精细美术、动作与原版小游戏的完整机制仍待后续制作。

## 当前可用内容

- 十九组可进入的三维基础场景，包括序章、监狱、逃离路线及三个结局的空间。
- 可见的第三人称主角，跟随镜头、拖动环顾、缩放和镜头避墙。
- “开始新游戏／继续游戏”按任务和道具条件解锁通路，显示当前目标、方向、随身物品及线索数量。
- 任务栏明确给出目的、逐段路线、目标位置和操作方式；金色标记直接写出下一处入口或要做的事。
- 可操作的墙面观察、齿轮归位与调谐、三本图书实地归位、物品查看接取、藏锤和狱警检查。
- 标准准备路线、石锤被没收后的备用路线、五份直接线索和两份旁听记录，连接三个结局。
- “场景总览”随时查看任意地点及资产清单，返回游戏后恢复原任务与位置。
- 剧情与场景查看分别保存；重新开始会备份上一份三维游戏记录，不读写原二维游戏存档。
- 通过本地模型清单替换基础资产，加载失败保留基础模型。

基础人物的走路摆动由程序驱动，只用于空间测试，不冒充已完成的正式角色骨骼或动作。
当前没有新增云端生成任务或消耗生成积分。

## 这一轮怎样贯通故事

剧情参考仓库中的原游戏主脚本和结局脚本，以独立任务事件组织，避免把旧版全局状态直接复制到三维场景里。

1. 开场进入牢房，靠近后墙擦去浮灰并尝试徒手撬动砂浆，从环境中发现需要工具的原因，再去院子找瑞德。电视、大门和手术台开场仍可在场景总览查看。
2. 与瑞德谈妥修理约定，把脱位齿轮归回空轴，根据声音和信号强度调谐，保持清晰信号两秒。回到瑞德身边旋转查看并接过石锤。到图书馆拿起三本书，按书脊字母送回对应书架，再向老布接过圣经。回牢房打开圣经，旋转并拖入石锤、合书，最后站到床边观察狱警进入、检查书桌并离开。
3. 获取海报、开始挖掘，一次操作处理碎土；漫长准备与岁月流逝自动衔接到最后一夜，在牢房整理管网地图。
4. 进入办公室、藏身、找到保险柜、调包账本，返回通道完成挖掘。
5. 借雷声砸管、穿过地下管网、到达雨夜出口，再进入对应结局。

没有藏好石锤就接受检查，会进入禁闭、听取老布建议、办公室搜查和找回工具的备用路线；训诫、等待开门与过夜自动衔接，之后重新汇入逃离主线。风险选择会明确说明没收后果，不与普通主线混为同一种按钮。

自动衔接保留原任务事件，旧存档可逐项重放，再推进到下一项需要操作的任务。自动转场后丢弃旧场景的位置；仍在原场景时保留站位。“场景查看”继续使用独立记录。

| 结局 | 进入条件 | 可游玩顺序 |
|---|---|---|
| 相逢的海滩 | 已取得瑞德线索，且未满足调查结局条件 | 瑞德到橡树根旁开盒读信、乘车赴约、海边重逢 |
| 高墙下的名单 | 五份直接线索，或至少四份直接线索与两份旁听记录 | 核对证据、寄信、调查医疗机构、补全记录、抓捕、结语 |
| 形同陌路 | 不满足以上条件 | 安迪银行取款、沿海驾车、修船；切换瑞德完成超市工作与自主决定 |

调查结局优先判定。普通的“与瑞德交谈”任务不自动取得其线索，需要主动选择追问。角色在对应结局阶段切换，始终使用第三人称镜头。

收音机、物品交付和藏锤采用独立三维近景操作，图书归位直接使用第三人称场景中的整理桌和分类书架。地图顺序、雷声砸管及超市装袋仍采用简化交互面板。驾驶、押送、时间流逝通过叙事转场连接；未实现完整驾驶、潜行、管道爬行动作或原版小游戏机制。

本轮检查聚焦任务能否继续、各分支能否结束、保存能否恢复、查看场景是否影响剧情。碰撞尺寸、镜头遮挡、动作和正式模型尺度留到资产接入后统一打磨。

## 逐步替换正式模型

把文件放进应用的公开资产目录，再编辑模型清单。

- 文件目录：
  `public/assets/models/`
- 模型清单：
  `public/assets/models.json`

清单示例（示例文件不随基础版提供，获得真实模型后再填写）：

```json
{
  "version": 1,
  "models": {
    "red": { "url": "/assets/models/red.glb", "height": 2.5 },
    "bed": { "url": "/assets/models/bed.glb", "height": 1.2 }
  }
}
```

中文字段说明：版本、模型映射、文件地址与目标高度。
使用 GLB（二进制三维模型）格式，文件地址限定当前应用的模型目录，不能填入密钥或临时签名地址。
普通道具按目标高度缩放，脚底归零；可选朝向字段使用弧度。
带骨骼的模型使用保留骨架的复制方式；若文件含动画，基础预览播放实际存在的第一个片段。
待机、行走、持物等动作与任务的切换，属于后续角色控制接入工作。

每个场景还提供“场景标识加建筑后缀”的整体建筑替换位，例如：

```json
{
  "cell-architecture": {
    "url": "/assets/models/cell-shell.glb",
    "normalize": false
  }
}
```

中文字段说明：牢房建筑槽位、模型地址、关闭尺寸归一化。
整体建筑必须使用与基础版相同的米制尺寸、中心原点、地面高度和门洞位置。
建筑替换只更新外观，不自动移动碰撞、人物站位或出入口；这些应在场景验收中同步核对。

当前可复用资产标识包括：床、桌椅、书架、收音机、海报、保险柜、人物、车辆与树木。
具体英文标识集中在场景数据和几何套件中，它们是代码连接键，不是界面文字。

## 玩法完整度核查与建模分级

截至二〇二六年十月三十一日，任务骨架可以贯通，正式玩法仍处于简化阶段。早期准备段已加入实际观察、操作、搬运和检查，后续逃离与结局仍需补齐。任务节点分布在不同分支，并非一局全部经历；地图顺序、雷声挥锤和商品装袋仍是简化面板挑战。

检查范围是当前三维代码与原二维对应段落。两条准备路线、三十二种直接线索组合和四种旁听组合，共二百五十六种情形可贯通并逐步恢复存档。状态测试不能替代真实移动、动作、镜头和小游戏体验验收，也不代表所有三维玩法已还原。

### 石锤取得前后的检查

当前前置链为：墙面观察与徒手尝试 → 与瑞德谈妥约定 → 归位传动齿轮并调谐 → 向瑞德接过石锤 → 实地归位三本图书 → 向老布接过圣经 → 打开书、旋转放入石锤并合书 → 站到床边接受检查。

- 墙面需要拖动擦灰，再持续尝试撬动；键盘可按住空格完成同等操作。
- 收音机不是直接给出频率答案。打开后盖，将齿轮拖到空轴松手，再根据信号强度与声音调谐，持续稳定两秒才完成；关闭声音后视觉反馈仍可完成任务。
- 修好收音机不会立即获得石锤。玩家回到瑞德身边查看并收取，背包才更新。圣经同样需要在老布身边接过。
- 图书在整理桌逐本拿取，书脊编号对应三个分类书架。实际移动并在书架前放入；错放保留持书和已完成的归位。
- 藏锤按位置、方向、是否放入、是否合书判定，靠近正确位置会吸附。仅打开书或直接合书不会完成。
- 检查由床边触发，守卫走入、查看书桌、离开。离开床边、打开菜单或查看档案会暂停。未藏好而主动接受检查，会进入没收与找回工具的既有备用路线。
- 操作与持书状态保存到第二版存档；旧版存档自动补齐已跨过的观察和交付，不要求重领道具，不清空原进度。

近景操作提供方向键移动、字母键Ｒ旋转、空格放下等键盘替代方式。退出近景不会丢失已经放入的齿轮、石锤或已经归位的书。交互模型目前是程序制作的可操作示意部件，正式道具外观与角色交付、翻页、检查等精细动画仍可继续替换。

### 与场景搭建的接入边界

早期玩法通过现有海报位置取得墙面调查点，通过整理用图书取得拿书位置，通过前三个书架取得分类归位点，通过床、书桌和牢房门取得检查路线。附件跟随这些现有物件，建筑布局、陈设位置与碰撞由场景模块继续管理。

玩法状态、近景渲染与场景附件分别实现，切换场景时释放附件，纯环境查看不创建玩法人物或交互。场景同事保留现有资产标识即可调整位置；若改变书架数量、门口结构或道具尺寸，需要同步核对归位位置和操作空间。正式可动模型应保留封面、旋钮、传动件等独立部件，不能把它们与建筑合成一体。

### 玩法缺口与验收目标

| 环节 | 当前实现 | 尚缺少或需要决定的内容 | 顺序 |
|---|---|---|---|
| 开场与角色动机 | 已有墙面观察、持续试撬与工具用途对话 | 后续可补开场声音与人物表情 | 已接入 |
| 藏锤与检查 | 已有三维拖放、方向判定、合书和守卫检查过程 | 正式书本模型、角色手部与翻页、查房动画继续精修 | 已接入 |
| 海报与挖掘 | 挂海报和挖土均以确认按钮推进 | 墙面与洞口显隐、海报开合、持续挖掘反馈、碎土取得；模型状态必须与剧情一致 | 优先 |
| 倒土与岁月流逝 | 一次确认后自动完成后续准备并跨越二十年 | 原版的持续倒土、狱警靠近、被发现和检查点重试；用短演出表现长期准备 | 优先 |
| 办公室 | 交谈、藏身、掀刺绣、调包均可完成 | 典狱长离开后外观仍在；缺少巡查计时、藏身判定、保险柜揭示与账本拿取反馈 | 优先 |
| 地图与管网 | 记忆顺序面板，加方向标记引导出口 | 地图应能帮助真实寻路；缺少爬行动作、路线辨认与死路反馈 | 随后 |
| 雷声砸管 | 计时窗口内点击三次，错误点击不扣进度 | 没有雷声音效、挥锤动作、管段破损和失败重试；先决定要轻挑战还是高风险 | 优先 |
| 雨夜与情绪收束 | 雨粒子和文字确认后进入结局 | 环境声音、开放天空、抬头或舒展动作、节奏停留；不可因低频省略 | 优先 |
| 线索与调查结局 | 收集计数按规则选择结局，核对与寄信可推进 | 证据实物阅读、编号和日期的对应推理；目前主要依靠逐项交谈 | 随后 |
| 橡树、乘车与重逢 | 到目标处确认、转场和结语 | 寻树线索、盒盖与读信、乘车演出；海滩需补安迪等候并避免瑞德重复出现 | 随后 |
| 银行、公路与超市 | 办手续与驾驶为文字转场，商品一次领取再排序 | 若保留完整结局，补取物与工作反馈；银行可保持短演出，驾驶不必先做完整系统 | 随后 |

当前人物基本按场景固定摆放，尚未随剧情切换在场状态。二十年后的老布、典狱长离开办公室、海滩重逢时的安迪与瑞德，需要统一的剧情显隐规则。否则完成建模后，仍会出现人物与对白不一致。

备用路线直接衔接到最后一夜，跳过领取和挂上海报，而后续引导仍称“海报后的通道”。需明确该路线如何准备入口：补一个合并后的准备说明或任务，或者统一修改入口状态与引导，不能仅开放通路。

结局规则为：五份直接线索，或四份直接线索加两份旁听记录，进入调查结局；否则取得瑞德的可选线索进入重逢结局，其余进入各自生活结局。普通主线交谈不算取得瑞德线索。应通过对白和调查反馈让玩家理解这种差异，避免认真完成主线却不明白为何没能重逢。

### 场景使用分类

分类以当前任务路线为依据，并非玩家使用统计。常用程度、剧情重要性与模型数量是不同维度。场景总览可按四类筛选，每处环境的资产清单还列出所需状态，便于场景与玩法同时制作。

| 分类 | 场景 | 使用特点与制作建议 |
|---|---|---|
| 常用往返，三组 | 安迪的牢房、监区走廊、院子与监狱大门 | 准备阶段反复经过，优先统一尺度、入口、碰撞与人物交互位置 |
| 主线关键，六组 | 图书馆、办公室、挖掘通道、砸管处、地下管网、雨夜 | 三个结局前都要经过；砸管和雨夜虽出现少，仍要优先保证玩法与情绪效果 |
| 分支与结局，九组 | 禁闭室、手术室、橡树、公路、海滩、超市、银行、证据整理空间、医疗机构外景 | 按选定分支排期；公路和海滩跨两个结局复用，证据房在调查结局中也会往返 |
| 档案展示，一组 | 电视前的客厅 | 当前新游戏自动跳过，核心体验完成后再精修或恢复开场 |

十九组环境不能直接等同于十九个完整模型。院子里的图书馆与办公楼已有独立外观替换位；房间建筑、家具、互动部件及人物也要分开。主线常用道具如石锤、圣经、海报、收音机、图书、保险柜、账本应比纯背景装饰先完成。

### 三人协作建议

场景搭建者先确认建筑尺度、门口和交互留白，再补陈设与美术；玩法负责人负责前置状态、人物显隐、持物、交互成功与失败反馈。可先用“牢房—走廊—院子—图书馆”验证借锤、得书、藏锤这段完整体验，再制作办公室到雨夜的逃离高潮。分支场景按首版承诺的结局范围推进。

玩法接入尽量保留现有任务事件标识，避免破坏存档。按段验收：能到达、知道为何操作、能看见结果、失败能重试、刷新能继续，最后再检查场景美术与人物动作。功能完整度应按这些实际行为判断，不以“模型已替换”或“任务能通关”代替。
